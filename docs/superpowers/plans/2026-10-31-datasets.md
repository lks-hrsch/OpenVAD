# Dataset Retrieval Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `just fetch <dataset>` puts a public dataset under `$OPENVAD_DATA_DIR/datasets/raw/` with a verifiable `manifest.json`. The tasks below cover the first four of the 19 fetchers: LibriSpeech, its alignments, AVA-Speech and LibriVAD `medium`.

**Architecture:** One stdlib-only package `openvad_train.fetch`: shared helpers in `common.py` (data root, resumable download, hashing, manifest), one module with `fetch_<dataset>()` per dataset, dispatched by `main(argv)` in `__main__.py`.
AVA audio comes from ffmpeg reading the S3 mirror over HTTP; LibriVAD runs its own unmodified scripts in an isolated `uv run --no-project`.

**Tech Stack:** Python 3.12 stdlib (`urllib`, `tarfile`, `zipfile`, `hashlib`, `json`, `subprocess`), pytest, ffmpeg, uv, just.

**Spec:** `docs/superpowers/specs/2026-10-31-datasets-design.md`

## Global Constraints

- Data root: `OPENVAD_DATA_DIR`, default `./data`, always resolved to an absolute path.
- No new Python dependency; `training/pyproject.toml` stays `dependencies = ["numpy", "safetensors"]`.
- LibriSpeech splits: `train-clean-100`, `dev-clean`, `test-clean`; mirror `https://openslr.elda.org/resources/12`; MD5s from `https://www.openslr.org/resources/12/md5sum.txt`.
- Alignments: Zenodo record `2619474`, file `librispeech_alignments.zip`. Extract only `train-clean-100`, `train-clean-360`, `dev-clean` and `test-clean`.
- AVA: labels `https://research.google.com/ava/download/ava_speech_labels_v1.csv`, file list `https://s3.amazonaws.com/ava-dataset/annotations/ava_file_names_trainval_v2.1.txt`, videos `https://s3.amazonaws.com/ava-dataset/trainval/<file>`; segment start 900 s, duration 900 s; no resampling, no downmix. Both lists are checked against pinned SHA-256 hashes.
- LibriVAD: repo `LibriVAD/LibriVAD`, revision `bc641946f7df3a9515eb87d4ea194374f03a2dd3`, mirror arg `EU`, size `medium`, skip `Eval-ViT-MFCC/`.
- Never delete anything under `datasets/raw/` except the fetcher's own partial output and markers; never commit data.
- English, British spelling, no em dashes, Conventional Commits, commit trailer per session instructions.
- Ruff line length 120, basedpyright `standard` must pass (`just lint-py`).

## Review Focus

- Interrupted run (Ctrl-C mid-download or mid-extract): the dataset must not look complete afterwards; a re-run must finish it. Test: `test_main_resumes_without_manifest` (`training/tests/openvad_train/fetch/__main__.py`).
- Checksum mismatch: must raise with both hashes in the message and leave no extracted output. Test: `test_download_checksum_mismatch_raises` (`training/tests/openvad_train/fetch/common.py`).
- Relative `OPENVAD_DATA_DIR` (default `./data`) used by a subprocess with another cwd (LibriVAD): must be absolute. Test: `test_data_dir_is_absolute` (`training/tests/openvad_train/fetch/common.py`).
- AVA video in the labels but absent from the mirror: goes to `missing.txt`, run continues. Test: `test_mirror_map_reports_missing` (`training/tests/openvad_train/fetch/ava.py`).
- ffmpeg not installed: clear error before any download. Code: `require_ffmpeg` (`fetch/ava.py`); no test.

### Task 1: Shared helpers, LibriSpeech and alignments

**Files:**
- Create: `training/src/openvad_train/fetch/{__init__,__main__,common,librispeech,alignments}.py`
- Create: `training/tests/openvad_train/fetch/{__main__,common,librispeech,alignments}.py`
- Modify: `justfile` (add `fetch` recipe after `docs-generated`)

**Interfaces:**
- Produces:
  - `data_dir() -> Path`: absolute `OPENVAD_DATA_DIR` or `./data`.
  - `raw_dir(name: str) -> Path`: `data_dir() / "datasets/raw" / name`.
  - `cache_dir() -> Path`: `data_dir() / "cache"`.
  - `file_hash(path: Path, algo: str) -> str`: hex digest, `algo` is a `hashlib` name.
  - `download(url: str, dest: Path, *, md5: str | None = None, sha256: str | None = None, headers: dict[str, str] | None = None) -> Path`: writes `dest.with_suffix(dest.suffix + ".part")`, resumes it with an HTTP `Range` header when the server answers 206 (restart from 0 otherwise), verifies the given hash, renames to `dest`; raises `ValueError` naming expected and actual hash on mismatch and deletes the `.part`. Skips the network if `dest` exists and verifies.
  - `parse_md5sum(text: str) -> dict[str, str]`: file name to MD5 (in `librispeech.py`).
  - `count_tree(root: Path) -> tuple[int, int]`: number of regular files and total bytes under `root`, excluding `manifest.json`, dotfiles and `__pycache__`.
  - `write_manifest(root: Path, info: dict) -> None`: writes `root / "manifest.json"` with `info` plus `files`, `bytes` from `count_tree`, `retrieved` (ISO date); sorted keys, indent 2.
  - `is_complete(root: Path) -> bool`: manifest exists and `count_tree(root)` equals its `files` and `bytes`.
  - `fetch_librispeech() -> None`, `fetch_alignments() -> None`.
  - `FETCHERS: dict[str, Callable[[], None]]`, `main(argv: list[str] | None = None) -> None`: one positional `dataset` choice; skips with a message when `is_complete(raw_dir(name))`. In `__main__.py`. A manifest that does not verify raises an error, and a run holds a local lock and a lock file on the share.

- [ ] **Step 3: Implement `fetch_librispeech()` and `fetch_alignments()`**

- `fetch_librispeech`: download `md5sum.txt`, then per split `download(f"{MIRROR}/{split}.tar.gz", cache_dir() / name, md5=...)`, extract with `tarfile.open(...).extractall(raw_dir("librispeech"), filter=tar_filter)`, with a marker per extracted split; `write_manifest` with `dataset`, `licence: "CC BY 4.0"`, `use`, `sources: [{"url", "md5"}]`, `splits`; then delete the archives and markers.

### Task 2: AVA-Speech

**Interfaces:**
- Consumes: `download`, `file_hash`, `raw_dir`, `write_manifest` (Task 1).
- Produces:
  - `AVA_START_S = 900`, `AVA_DURATION_S = 900`.
  - `ava_video_ids(labels_csv: str) -> list[str]`: sorted unique IDs from column 1.
  - `ava_mirror_map(ids: list[str], file_list: str) -> tuple[dict[str, str], list[str]]`: ID to mirror file name (`<id>.<ext>`), and the sorted missing IDs.
  - `ava_ffmpeg_cmd(url: str, out: Path) -> list[str]`.
  - `require_ffmpeg() -> None`: raises `RuntimeError("ffmpeg not found on PATH ...")` if `shutil.which("ffmpeg")` and `shutil.which("ffprobe")` are not both found.
  - `fetch_ava() -> None`, registered in `FETCHERS` as `"ava"`.

- [ ] **Step 1: Tests** in `training/tests/openvad_train/fetch/ava.py`, among them `test_mirror_map_reports_missing` and `test_ffmpeg_cmd_cuts_labelled_span_without_resampling`.

- [ ] **Step 2: Implement the four functions** per Interfaces.

`ava_ffmpeg_cmd` returns `["ffmpeg", "-nostdin", "-loglevel", "error", "-y", "-rw_timeout", RW_TIMEOUT_US, "-ss", "900", "-i", url, "-t", "900", "-vn", "-c:a", "flac", str(out)]`.

- [ ] **Step 3: Implement `fetch_ava()`**

- `require_ffmpeg()` first.
- Download the labels CSV and the mirror file list into `raw_dir("ava-speech")`, both against pinned SHA-256 hashes, `ava_mirror_map`, write `missing.txt` (one ID per line).
- For each found ID, skip if `audio/<id>.flac` exists; else run ffmpeg to `audio/<id>.part.flac` (ffmpeg picks the muxer from the extension) and rename to `audio/<id>.flac` on success; on failure delete the part file, continue, and raise after the loop naming the failed IDs. A cut shorter than the labelled span counts as failed.
- Run up to 4 ffmpeg processes in parallel (`concurrent.futures.ThreadPoolExecutor(4)` + `subprocess.run(check=True)`).
- Per file, `ffprobe -v error -show_entries format=start_time -of csv=p=0 <url>` gives the container `start_time`; record it when non-zero.
- Manifest: `licence: "labels CC BY 4.0; audio copyright of the YouTube uploaders, not redistributable"`, `use`, `ffmpeg`, `offset_s: 900` with the note `t_audio = t_label - 900`, `videos` (count found), `missing` (count), per-file `sha256` and `start_time`.

- [ ] **Step 4: Add ffmpeg to the flake** dev shell `packages` list, after `pkgs.uv`, and check: `nix flake check` (skip on a machine without Nix and say so).

- [ ] **Step 3: Implement `fetch_librivad()`**

1. Tree: `https://huggingface.co/api/datasets/LibriVAD/LibriVAD/tree/{LIBRIVAD_REV}?recursive=true`; download each `librivad_files` path from `https://huggingface.co/datasets/LibriVAD/LibriVAD/resolve/{LIBRIVAD_REV}/{path}` into `raw_dir("librivad") / "repo"`.
